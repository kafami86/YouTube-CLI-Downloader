# yt-dlp CLI Script Downloader
# 🎬 YouTube CLI Downloader  Download **YouTube videos and MP3 audio quickly and easily** using a clean and powerful CLI interface.  ### ✨ Features  🎥 **Download MP4 videos** 🎵 **Download MP3 audio** 📺 Choose your preferred video quality 🎚️ Select audio quality 📋 Download playlists ⚡ Fast downloads powered by **yt-dlp** 🔧 Automatic video + audio merging with **FFmpeg** 📊 Beautiful real-time progress and download information 🌑 Clean dark **YouTube-inspired CLI design** 🛠️ Easy configuration and advanced options  ---  ### ⚠️ First Run  The project does **not include FFmpeg and yt-dlp by default**.  Before your first download, open the application and run:  ```text 🔄 Update yt-dlp 🔄 Update FFmpeg ```  This will automatically download the required components into the project.  ✅ After that, the downloader is ready to use.  ---  ### 🚀 Easy to Use  Simply run:  ```bash python main.py ```  Then choose:  ```text [1] 🎥 Download MP4 [2] 🎵 Download MP3 [3] 📺 Download Playlist [4] 🔍 Video Information [5] ⚙️ Settings ```  Paste your YouTube URL and let the application handle the rest.  ### 💡 Example  ```text 🎬 YouTube URL: > https://youtube.com/watch?v=...  🔎 Fetching video information... ⬇️ Downloading... 🔧 Processing with FFmpeg... ✅ Download complete!  📁 Saved to: download/video/ ```  For audio:  ```text 🎵 MP3 Download  🔎 Processing... 🎵 Extracting audio... ✅ Download complete!  📁 Saved to: download/audio/ ```  ### ❤️ Powered By  **Python + yt-dlp + FFmpeg**  A simple way to download your YouTube **MP4 and MP3 files** directly from the command line.
